Guia por Step
0
Setup — Preparar o Terreno
Observação silenciosa · ativação
Lidera · cria curiosidade · não explica
10 min
📢 Script de abertura

"Antes de ligar qualquer computador, preciso que olhem para esta mesa. Cinco objetos. Dois minutos em silêncio. Escrevam numa folha: o que têm estes objetos em comum? Qualquer resposta é válida. Não há erros."

  • Colocar os 5 objetos na mesa antes de os participantes entrarem
  • Deixar 2 minutos de silêncio real — não interromper
  • Recolher as respostas oralmente (1 por pessoa, sem comentar ainda)
  • Registar as respostas visíveis no quadro/ecrã
  • Fazer a pergunta de ligação: "E se eu vos disser que todos estes objetos podem ser descritos com apenas dois números?"
▶

"Vamos descobrir como. Abram o browser."

1
Identificar — Ler o Mundo com Novos Olhos
Exploração · Brief Canvas
Circula · faz perguntas · não dá respostas
20 min
📢 Script de abertura

"Cada grupo vai explorar a aplicação durante 10 minutos. Sem instruções. Explorem. Se ficarem presos, a primeira pergunta que vou fazer é: 'O que já tentaram?' Depois, cada grupo preenche o Brief Canvas — vou circular e validar o campo 4."

Perguntas de discussão (usar enquanto circula)

  • O que acontece quando mudas o x de 0 para 2?
  • Consegues criar uma forma que te lembre um objeto real?
  • Se o y controla a altura, o que controla a forma da curva?
  • Porque é que x não pode ser negativo? O que significa fisicamente?
  • Quantos pontos precisas no mínimo? Porque é que isso faz sentido?

Brief Canvas — orientação por campo

1
O que descobrimos: Aguarda que os grupos observem pelo menos 3 exemplos antes de preencher
2
Para que serve: Empurra para contexto real — "Serve para que? Para quem?"
3
Que problema resolve: Aceita respostas amplas — "Não ter impressoras no mundo inteiro" é válido
4
Ideia de desafio (validar tu): Se vago: "Que objeto específico? Quem vai usar?" · Se ambicioso demais: "Qual é a versão mais simples que já prova a ideia?"
5
Critérios de sucesso: Deve ser mensurável — "A forma parece um copo" é melhor que "ficou bem"
▶

"Têm o vosso desafio validado. Agora têm 50 minutos. O relógio está a correr."

2
Desafiar — Mãos à Obra com Propósito
Design · impressão · publicação
Calibra · não resolve · celebra a tentativa
50 min
📢 Script de abertura

"Regra de ouro desta sessão: cada vez que me pedirem para resolver um problema, vou fazer-vos uma pergunta em vez disso. Não é crueldade — é o método. Quando descobrem vocês próprios, fica. Quando eu digo, esquece-se em dois minutos."

0–15 min · Exploração dirigida
Grupos criam primeiros modelos, experimentam livremente. Circula e faz nota de quem está a progredir e quem está preso.
15–35 min · Construção intencional
Grupos trabalham no objeto do Brief Canvas. Quando um grupo termina um modelo: "Exporta já o STL. Agora tens uma versão 1. O que queres melhorar?"
35–50 min · Preparação para impressão
Abrir slicer com os STLs. Orientar o objeto (base para baixo, sem suportes). Confirmar espessura mínima de parede ≥ 1.2mm. Iniciar fila de impressão — tempo estimado por objeto: 20–45 min.

Perguntas de Sócrates (para grupos bloqueados)

  • O que querias que acontecesse? O que está a acontecer em vez disso?
  • Muda apenas o primeiro ponto. O que mudou na forma?
  • Qual é o ponto mais importante para o teu objeto? Porquê?
  • Se descrevesses a forma em palavras — estreita no meio, larga em cima — como traduzias isso para x e y?
▶

"Cinco minutos. Guardem o JSON, exportem o STL, e preparem uma coisa para mostrar — pode ser a versão que ficou melhor, não precisa de ser perfeita."

3
Validar — Mostrar, Questionar, Projetar
Galeria · feedback · critérios
Modera · valoriza processo E resultado
20 min
📢 Script de abertura

"Cada grupo tem 3 minutos. Mostram o objeto no ecrã, dizem o nome, para que serve, e uma coisa que descobriram durante o processo. Depois, cada grupo dá feedback com post-its: amarelo — o que funcionou; verde — uma sugestão. Sem 'está bonito' — queremos feedback específico."

  • Projetar o modelo 3D na app com rotação automática ativada
  • Mostrar o JSON no ecrã enquanto apresentam
  • Objetos impressos que já terminaram: colocar na mesa central

Perguntas de discussão para a galeria

  • Qual foi a decisão de design mais difícil?
  • Se tivessem mais 10 minutos, o que mudavam?
  • Alguém consegue identificar o ponto mais importante no JSON deste grupo?
▶

"Ótimo trabalho. Agora o mais importante: o que ficou em cada um de vocês."

4
Retrospetiva — O Que Ficou em Mim?
Reflexão individual · partilha
Cria espaço · não avalia · regista
15 min
📢 Script de abertura

"Dois minutos em silêncio. Escrevam três frases: 'Aprendi que...' / 'Fiquei surpreendido quando...' / 'Na próxima vez quero...' Não vou recolher. É para vocês. Depois cada um partilha uma — a que quiser."

  • Quem usou vocabulário técnico correto (JSON, coordenadas, revolução)?
  • Algum grupo definiu critérios de sucesso no Canvas e avaliou contra eles?
  • Quem demonstrou iteração deliberada (tentou, falhou, ajustou, tentou de novo)?
  • Nível de confiança antes/depois — pedir show of hands: 1–2–3–4–5
⚡ Gamificação
⚡

Sensor Pick

Ativa quando observas um momento de descoberta genuína: "Para todos — o grupo X acabou de descobrir algo interessante. Grupo X, expliquem em 30 segundos." Não anunciar antecipadamente — o efeito de surpresa é intencional.
🏆

Prémio de Argumento

No Step 3, o grupo com o critério de sucesso mais preciso e verificável ganha reconhecimento: "Este grupo definiu antes de começar que ia criar uma forma com gargalo visível a pelo menos 1cm. Fizeram-no? Isso é design com propósito."

🔴 Contingências
1
A aplicação CODE3D não carrega / browser com erro
Abre o ficheiro index.html diretamente do disco local (ter cópia offline em todos os PCs). Se não houver cópia offline: muda para modo demonstração coletiva num único PC projetado.
2
Um grupo está muito atrasado em relação aos outros
Simplifica o Brief Canvas para campos 3 e 4 apenas. Sugere começar pelo exemplo "Vaso" e fazer apenas 2 alterações. O objetivo é ter uma experiência completa de ciclo, mesmo que o objeto seja simples.
3
A impressão falhou a meio
Não interromper o Step 2 para resolver. Resolve em paralelo. Se o objeto falhou completamente, usa um objeto impresso anteriormente como substituto. A falha de impressão é, ela própria, conteúdo pedagógico para o Step 4.
4
STL com paredes demasiado finas — slicer não gera geometria
Mostra ao grupo o problema no slicer (paredes em vermelho ou ausentes). Pergunta: "O que precisamos de mudar no JSON para que as paredes fiquem mais grossas?" — a resposta é aumentar os valores de x em todos os pontos. Lição de física aplicada.
5
Um grupo terminou o Step 2 muito cedo (20+ min de sobra)
Ativa o desafio extra (modo fractal). Se o fractal também estiver feito: "Cria agora um segundo objeto que seja complementar ao primeiro — juntos, contam uma história."
6
Participante sem nenhuma experiência com código ou dados
Emparelha com alguém mais experiente, mas garante que a pessoa sem experiência é quem digita os números — não quem observa. Mover um número e ver a forma mudar é o núcleo da aprendizagem.
7
Grupo que questiona "para que serve isto no mundo real?"
"Boa pergunta. Este software usa o mesmo princípio que o software de design de carrocerias de carros, de garrafas de perfume, de componentes de aviões. A diferença é que eles usam interfaces mais complexas. O princípio matemático é o mesmo que estás a usar agora."
